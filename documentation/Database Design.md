# CampusShield-AI Database Design

## Database Tables

The project will have approximately the following tables:

| Table Name      | Description                          |
|-----------------|--------------------------------------|
| Users           | Stores user account information      |
| Incidents       | Records of reported incidents        |
| Predictions     | AI-generated crime predictions       |
| CrimeHotspots   | Identified crime hotspot locations   |
| Alerts          | System and user alerts               |
| Notifications   | User notification records            |
| Locations       | Campus location data                 |
| Roles           | User roles and permissions           |
| ActivityLogs    | System activity and audit logs       |

---

## Module 1: Authentication

| Feature         | Description                          |
|-----------------|--------------------------------------|
| Login           | User login with credentials          |
| Register        | New user registration                |
| Forgot Password | Password reset flow                  |
| Roles           | Role-based access control (RBAC)     |
| JWT             | JSON Web Token authentication        |
